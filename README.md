## 金币商店、皮肤与排行榜（2026-10-16）

- **皮肤商店**：答对一道题并领取奖励可获得 10 金币，金币累积后解锁皮肤。共 6 套：森林原野（默认，免费）、深海蓝 120、樱花雾 180、琥珀金 240、午夜墨 320、矩阵绿 420。皮肤只改配色，不影响题目、作答记录和积分；金币与皮肤存在账号里，换设备仍有效。
- 金币按题目去重：同一道题重复领取奖励不会重复发放金币（钱包内 `credited` 列表记录已发放的题号），领取接口返回最新余额。
- 皮肤以 `:root[data-skin=...]` 覆盖调色板变量，因此每个组件自动跟随；浅色/深色各有一套取值。皮肤选择在首帧前写入 `document.documentElement`，刷新不会闪回默认配色。
- **同学排行榜**：只统计已提交的作答记录，展示刷题人数、答对题数、正确率和练习次数；正确率按全部提交计算，含待判分。没有提交记录的同学不入榜，停用账号自动退出榜单。
- **匿名参与**：勾选后其他同学只看到稳定的「匿名同学 NNNN」代号（由用户 ID 派生，刷新不变），自己始终能看到真实姓名。排行榜只返回统计数字，不包含作答内容、错题或草稿。
